# AWS Study Decks

Flashcard decks for the AWS Solutions Architect exams.

- **Quick Cards** — every service, one line each. Coverage pass. (Associate)
- **Concept Cards** — 25 contrast sets organised by deciding axis. Discrimination pass. (SAA-C03)
- **Professional Cards** — 29 contrast sets at professional depth. Assumes the two above and repeats neither. (SAP-C02)

Static HTML, no build step. Served by GitHub Pages directly from the `main` branch — every push to `main` goes live at <https://serakim1105.github.io/aws/>.
