# AWS SAA Study Decks

Two flashcard decks for the AWS Solutions Architect – Associate exam.

- **Quick Cards** — every service, one line each. Coverage pass.
- **Concept Cards** — contrast sets organised by deciding axis. Discrimination pass.

Static HTML, no build step. Served by GitHub Pages directly from the `main` branch — every push to `main` goes live at <https://serakim1105.github.io/aws/>.
