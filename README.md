# AWS Study Decks

Flashcards for the AWS Solutions Architect Professional exam (SAP-C03), in one deck.

- **Professional Cards** — the one deck to review, in four parts: notes at professional depth, added section by section while studying; contrast sets organised by deciding axis; a one-line recall pass for every service; and lookup tables for where each AWS managed log goes and which storage services survive an AZ or Region. (SAP-C03)
- **Quick Cards**, **Concept Cards**, **Logs and Multi-AZ Cards** — the earlier separate decks. Their content now lives in Professional Cards; the pages are kept as they were and are no longer updated.

Static HTML, no build step. Served by GitHub Pages directly from the `main` branch — every push to `main` goes live at <https://serakim1105.github.io/aws/>.
